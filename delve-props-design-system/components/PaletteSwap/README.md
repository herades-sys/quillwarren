# Palette swap

Every sample prop under its source inks and two example map styles, proving the files survive the renderer's colour swap.

Nothing to pass in. The lower rows are the same files with `#000000`, `#FFFFFF` and `#999999` replaced as whole strings — which is why a prop may contain those three values and nothing else. The sepia and night palettes are illustrations, not Delve's real map styles. A prop that only reads in the source row (for example one that relies on `shade` being mid-grey against white) needs more value separation or an outline.
