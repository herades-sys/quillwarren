# Anatomy

Where each ink and each line weight goes, annotated on the chest at 3.6× map scale, with the 4-unit margin band shown.

Nothing to pass in. Read it with the brand book's "Three inks" and "Line weights" rules: `stroke-outline` for silhouettes, `stroke-detail` for construction inside a piece (and for small hardware's own edge), `stroke-texture` for grain; `paper` for the main surface, `shade` for metal, `ink` for openings and rivet heads. The dashed square is one grid square; the shaded band inside it is `margin` and stays empty.
