# samples

The first batch, category `samples`. Each file is a standalone prop in the three source inks (`ink` #000000, `paper` #FFFFFF, `shade` #999999), 100 units per grid square; a map renderer recolours them per style.

- `table-round.svg` — 2×2. Round board table with two chairs tucked in at north and south. Blocks movement.
- `chest.svg` — 1×1. Closed chest, iron bands, lock facing south. Blocks movement.
- `barrel.svg` — 1×1. Barrel from above: hoops, stave ends, board head, bung hole. Blocks movement.
- `statue.svg` — 1×1. Cloaked figure with a planted sword on a bevelled square plinth, facing south. Blocks sight.
