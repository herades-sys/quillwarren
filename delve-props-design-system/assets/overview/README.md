# overview

One overview card per batch, named after its category. Not props: they carry id labels and use `parchment`, `grid-faint` and `label-ink`, which never appear in a prop file.

- `samples.svg` — the samples batch on parchment with the 100-unit grid, 1000×400 units.
- `samples.png` — the same card rendered at 140 px per square.
